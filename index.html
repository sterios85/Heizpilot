Erster Messwert-Abgleich

Öffne ELESION und übertrage die dort angezeigten Werte eines Thermostats. Damit können wir die Regelberechnung mit real abgelesenen Werten prüfen – ohne Verbindung zur Hardware.

Die Werte werden nur auf diesem Gerät im Browser gespeichert. Der ELESION-Sollwert wird nicht an die Heizung gesendet.

Vorbereitung der echten Anbindung

  1. In ELESION bleibt alles unverändert. Keine Geräte entfernen oder zurücksetzen.
  2. Prüfen, ob das ELESION-Konto über ein Tuya-IoT-Entwicklerprojekt verknüpft werden kann.
  3. Nur wenn die Verknüpfung gelingt: Geräteliste und unterstützte Datenpunkte auslesen.
  4. Zunächst einen Thermostat nur lesen, danach eine kleine Sollwertänderung kontrolliert testen.
  5. Für GitHub Pages einen geschützten Verbindungsdienst einrichten; API-Geheimnisse niemals in diese Webseite schreiben.

Ein dauerhaft kostenloser API-Zugang und eine Hintergrundautomatik sind noch nicht bestätigt. GitHub Pages allein kann keine 24-Stunden-Regelung ausführen.

Export enthält deine lokal gespeicherten Räume und Messwerte, aber keine Passwörter oder API-Schlüssel. Teile ihn nur bewusst.
